En 2023, le modèle explique environ 81 % de la variabilité du score de bonheur (R² = 0,8101, R² ajusté = 0,7898), soit légèrement plus qu’en 2015. Le test global de Fisher reste très significatif (p-value < 2.2e-16), ce qui confirme que l’ensemble des variables apporte une information utile pour expliquer happiness_score.

Au seuil de 5 %, les variables significatives en 2023 sont :

En résumé, entre 2015 et 2023, le pouvoir explicatif du modèle augmente légèrement (R² passe d’environ 0,77 à 0,81). Les effets robustes et stables concernent surtout gdp_log et freedom_to_choose (positifs). En 2023, des variables institutionnelles et démographiques comme voice_accountability (positif) et active_population_rate (négatif) ressortent, tandis que cpi change de signe par rapport à 2015 mais reste non significative, donc ce point ne doit pas être interprété comme un résultat solide à ce stade.

  1. Validation des modèles linéaires (graphes de résidus)

À cette étape, on vérifie visuellement les hypothèses du modèle linéaire (linéarité, normalité des résidus, variance constante, et présence éventuelle de points influents)

  • Pour le modèle 2015 :

Résidus / valeurs ajustées

Le nuage est globalement centré autour de 0. La courbe rouge montre une légère forme en U très faible, ce qui suggère une non-linéarité légère mais limitée. On observe quelques résidus atypiques, étiquetés comme 14, 109 et 60, sans structure dominante.

QQ-plot

Les points suivent bien la droite au centre, mais on voit des écarts dans les extrémités, surtout dans la queue gauche (ex. 60, 109) et dans la queue droite (ex. 140). La normalité est donc globalement raisonnable, avec des queues un peu plus “lourdes” que la normale.

Scale-Location

La dispersion des résidus standardisés est assez stable sur l’ensemble des valeurs ajustées. La courbe rouge est légèrement bombée au milieu, mais l’hétéroscédasticité semble faible à modérée, et ne remet pas en cause l’usage du modèle.

Résidus standardisés / leverage

La majorité des points ont un leverage faible. Un point à leverage très élevé est visible (à droite), ce qui peut indiquer un pays particulièrement atypique sur les variables explicatives. Les distances de Cook ne semblent pas franchir de seuil critique, mais ces observations méritent d’être surveillées car elles peuvent influencer certains coefficients.

  • Pour le modèle 2023 :

Résidus / valeurs ajustées

Le nuage reste globalement centré autour de 0, mais la courbe rouge montre une tendance légèrement décroissante quand les valeurs ajustées augmentent. Cela indique un biais léger selon le niveau de bonheur, donc une non-linéarité plus marquée qu’en 2015.

QQ-plot

L’écart à la droite est plus visible qu’en 2015, surtout dans la queue gauche avec quelques points très extrêmes (ex. 124, 121, 116). La normalité des résidus est donc moins bien respectée en 2023, principalement à cause de ces observations atypiques.

Scale-Location

La courbe rouge décroît globalement, ce qui suggère une variance des résidus un peu plus forte pour les valeurs ajustées faibles, puis plus faible pour les valeurs ajustées élevées. On est sur une hétéroscédasticité modérée.

Résidus standardisés / leverage

Quelques points combinent résidus importants et leverage non négligeable (ex. 124, 121), ce qui les rend potentiellement influents. Là encore, rien n’indique une invalidité totale du modèle, mais ces pays peuvent peser sur l’estimation de certains paramètres.

En résumé, le modèle linéaire est globalement satisfaisant en 2015. En 2023, les diagnostics suggèrent davantage de non-linéarité, une normalité des résidus moins bonne à cause de quelques pays extrêmes, et une hétéroscédasticité modérée. Le modèle est exploitable, mais l’interprétation des coefficients doit être faite avec plus de prudence, en particulier à cause des observations potentiellement influentes.

set.seed(123)

eval_cv <- function(df, models, v = 10, repeats = 5) {
  folds <- rsample::vfold_cv(df, v = v, repeats = repeats)

  res <- purrr::map_dfr(folds$splits, function(split) {
    train <- rsample::analysis(split)
    test  <- rsample::assessment(split)

    purrr::map_dfr(names(models), function(mn) {
      fit <- models[[mn]](train)
      pred <- predict(fit, newdata = test)
      obs <- test$happiness_score

      rmse <- sqrt(mean((obs - pred)^2, na.rm = TRUE))
      mae  <- mean(abs(obs - pred), na.rm = TRUE)
      r2   <- 1 - sum((obs - pred)^2, na.rm = TRUE) /
        sum((obs - mean(obs, na.rm = TRUE))^2, na.rm = TRUE)

      data.frame(model = mn, RMSE = rmse, MAE = mae, R2 = r2)
    })
  })

  res %>%
    group_by(model) %>%
    summarise(
      RMSE_mean = mean(RMSE), RMSE_sd = sd(RMSE),
      MAE_mean  = mean(MAE),  MAE_sd  = sd(MAE),
      R2_mean   = mean(R2),   R2_sd   = sd(R2),
      .groups = "drop"
    ) %>%
    arrange(RMSE_mean)
}

# CV Ridge/Lasso via rsample + glmnet
eval_cv_glmnet <- function(df, vars_x, v = 10, repeats = 5, alpha = 0) {
  folds <- rsample::vfold_cv(df, v = v, repeats = repeats)

  res <- purrr::map_dfr(folds$splits, function(split) {
    train <- rsample::analysis(split)
    test  <- rsample::assessment(split)

    # Matrices modèle (glmnet veut des matrices numériques)
    x_train <- model.matrix(
      as.formula(paste("happiness_score ~", paste(vars_x, collapse = " + "))),
      data = train
    )[ , -1, drop = FALSE]  # enlever intercept

    y_train <- train$happiness_score

    x_test <- model.matrix(
      as.formula(paste("happiness_score ~", paste(vars_x, collapse = " + "))),
      data = test
    )[ , -1, drop = FALSE]

    y_test <- test$happiness_score

    # CV interne glmnet pour choisir lambda sur le train uniquement
    cvfit <- glmnet::cv.glmnet(
      x = x_train, y = y_train,
      alpha = alpha,
      standardize = TRUE
    )

    pred <- as.numeric(predict(cvfit, newx = x_test, s = "lambda.min"))

    rmse <- sqrt(mean((y_test - pred)^2, na.rm = TRUE))
    mae  <- mean(abs(y_test - pred), na.rm = TRUE)
    r2   <- 1 - sum((y_test - pred)^2, na.rm = TRUE) /
      sum((y_test - mean(y_test, na.rm = TRUE))^2, na.rm = TRUE)

    data.frame(RMSE = rmse, MAE = mae, R2 = r2)
  })

  res %>%
    summarise(
      RMSE_mean = mean(RMSE), RMSE_sd = sd(RMSE),
      MAE_mean  = mean(MAE),  MAE_sd  = sd(MAE),
      R2_mean   = mean(R2),   R2_sd   = sd(R2)
    )
}

  1. Comparaison globale de tous les modèles

L’objectif était de modéliser le score de bonheur (happiness_score) en 2015 et en 2023 à partir d’un ensemble de variables socio-économiques, institutionnelles et environnementales, puis de choisir un modèle qui généralise le mieux.

Sur les deux années, les modèles linéaires ont un bon pouvoir explicatif en ajustement (R² ≈ 0,77 en 2015 et ≈ 0,81 en 2023 pour le modèle complet). Les déterminants les plus stables et les plus robustes sont gdp_log et freedom_to_choose, qui ressortent positifs dans les deux périodes. En 2015, life_expectancy est également un contributeur important, alors qu’en 2023 son effet propre devient faible une fois les autres variables contrôlées. Côté institutionnel, voice_accountability apparaît plus nettement en 2023. Les variables environnementales apportent peu d’information supplémentaire dans ce cadre linéaire, une fois les variables de développement et institutionnelles prises en compte.

Les diagnostics mettent en évidence deux limites importantes. D’abord, une colinéarité marquée, surtout autour du bloc institutionnel et développement (cpi, government_effectiveness, et gdp_log), confirmée par des VIF élevés. Ensuite, la présence d’observations influentes, particulièrement en 2023, ce qui impose de rester prudent dans l’interprétation causale et même dans l’interprétation fine de certains coefficients.

Pour le choix de modèle, la validation croisée montre que le modèle StepAIC (formule fixée) est le meilleur en prédiction hors échantillon sur les deux années. En 2015, il obtient un RMSE moyen d’environ 0,588, légèrement meilleur que Ridge (≈ 0,594) et meilleur que les modèles complet et réduit. En 2023, l’écart est plus net, avec un RMSE moyen d’environ 0,530 pour StepAIC, contre ≈ 0,55 pour Ridge et Elastic Net, et ≈ 0,552 pour les modèles complet et réduit. Le graphique final synthétise bien ce résultat, StepAIC est systématiquement parmi les plus performants, et 2023 présente globalement des RMSE plus faibles que 2015.

Enfin, la régularisation (Ridge, Lasso, Elastic Net) ne surpasse pas StepAIC en RMSE dans ces données, mais elle reste pertinente comme réponse à la colinéarité car elle stabilise l’estimation des coefficients et peut limiter la variance. Par la suite, si l’objectif prioritaire devient la prédiction, StepAIC sera le meilleur choix. Si l’objectif nécessite davantage la robustesse des coefficients dans un contexte colinéaire, Ridge ou Elastic Net peuvent rester intéressants, à condition d’accepter une performance prédictive légèrement inférieure dans les résultats.
