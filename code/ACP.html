  1. Chargement des données et sélection des variables

Le fichier nettoyé dans le notebook nettoyage_des_données.ipynb, world_happiness_2015_clean.csv, est utilisé dans le cadre de cette ACP.

Certaines colonnes ne doivent pas être utilisées dans l’ACP car ce sont des identifiants ou des informations qualitatives :

  • rank
  • country
  • region
  • happiness_score
  • year

Voici les variables quantitatives restantes :

  • gpd_per_capita
  • social_support
  • healthy_life_expectancy
  • freedom_to_choose
  • generosity
  • corruption_perception

  1. Standardisation des données et matrice de corrélation

Afin de faire une ACP normée, on a besoin d’une matrice de données Z
