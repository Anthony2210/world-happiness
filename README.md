# World Happiness (2015–2024)

## Objectif du projet
Ce projet vise à analyser les facteurs du bien-être national à partir du jeu de données World Happiness (2015–2024).  
L’objectif principal est de comprendre :
- comment le score de bonheur (Ladder score) évolue au fil du temps,  
- quels facteurs socio-économiques, sociaux et institutionnels influencent le plus le bien-être d’un pays,  
- et d’identifier des profils de trajectoires selon les régions du monde.

---

## Contexte et source des données
Les données proviennent du [World Happiness Report](https://worldhappiness.report/), un projet soutenu par le Réseau des solutions pour le développement durable des Nations Unies (SDSN).  
Le jeu de données utilisé est disponible sur Kaggle :  
🔗 [World Happiness Dataset (2015–2024)](https://www.kaggle.com/datasets/yadiraespinoza/world-happiness-2015-2024)

Chaque fichier correspond à une année entre 2015 et 2024.  
Un fichier combiné (“world_happiness_combined.csv”) regroupe l’ensemble des années pour une analyse sur la décennie complète.
